### 🚀 Featured Projects

#### 🚗 [Production-Style Ride-Sharing Platform](https://github.com/YaroslavYaryk/go-uber-clone)
> Go · Kubernetes · RabbitMQ · gRPC · WebSockets · MongoDB · Stripe

A fully containerised ride-sharing backend inspired by Uber, built from scratch with a microservices architecture in Go. 4 independent services (API Gateway, Trip, Driver, Payment) communicate over a RabbitMQ topic exchange and gRPC. Features geohash-based real-time driver matching, WebSocket push updates to both rider and driver, OSRM route planning with dynamic fare calculation, and Stripe Checkout integration. Deployed to production on GKE with Google-managed SSL; Tilt used for a fast local Kubernetes dev loop.

`Go` `Kubernetes` `RabbitMQ` `gRPC` `WebSockets` `MongoDB` `Stripe` `GKE` `Tilt` `Next.js`

---

#### 💬 [InstaChat — Real-Time Messenger](https://github.com/YaroslavYaryk/django-channels-insta)
> Django Channels · DRF · React Native · PostgreSQL · WebSockets

A full-featured real-time messaging platform built with Django Channels (WebSockets) and Django REST Framework. Supports send, edit, delete, like, reply, and forward across conversations. Includes live online presence tracking and message delivery state via persistent WebSocket connections. Cross-platform: a single Django/Channels backend serves both a React web frontend and a React Native mobile app through a shared DRF API and WebSocket layer.

`Django Channels` `Django REST Framework` `React Native` `ReactJS` `PostgreSQL` `WebSockets`
